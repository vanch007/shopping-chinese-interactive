# 购物中文对练

适合越南学员的场景购物网页：从地图进入七个场景，查看商品、练习中文回复、听示范语音，并通过越南语理解台词。

[打开网页](https://vanch007.github.io/shopping-chinese-interactive/)

## 双音色与越南语辅助

- NPC 使用用户提供的 `vanch.m4a` 克隆音色，区分亲切迎客、耐心解释、温和议价和轻快回应。
- 玩家回复选项使用用户提供的 `Bạn khỏe không .m4a` 克隆音色，朗读语言为中文。
- 本次新制或重制 52 段语音：28 段 NPC、21 段玩家回复、3 段话题引导；模型为本地 MLX IndexTTS 2.5 8-bit。
- 49 句对话均有越南语翻译与用法解释，21 件商品另有词义或句型说明。
- 点击选项旁的喇叭可先试听；选中回复后，等玩家朗读结束再播放 NPC。重播按钮对应当前台词。
- 支持 1× / 0.85× 语速。播放失败可重试，不使用浏览器系统语音替代。
- 进入店铺时对话默认收起；手机上的解释可按需展开。越南语和拼音可以分别关闭。

## 独立文件

`index.html` 内嵌图片、数据与 MP3，是完整交付文件。完整下载后可通过支持本地 HTML 的浏览器离线打开；GitHub Pages 版本首次访问需要网络。原始声音参考文件不会打包或发布。

## 重建

修改 `template_game.html`、`game_data_rich.json` 或 `assets/` 中的素材后运行：

```sh
python3 compile_final_app.py
```

需要 Python 3 和 Pillow。构建会核查台词音频键和越南语字段，不依赖被忽略的 `audio_b64.json` 缓存。

本地音频生成与检查记录保存在忽略的 `work/`，发布验收摘要见 [语音版本记录](docs/voice-release-2026-10-09.md)。当前版本仍使用原有七场景流程；手机优先、多轮剧情分支属于下一轮设计。
