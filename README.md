## ✨ 项目特色 (Key Features)

- 🎮 **像互动游戏一样逛街探索 (RPG Shopping Game Flow)**：
  - **大城全景地图**：3D 等距视角购物街区，无缝点击进入不同商铺。
  - **7 大特色购物场景**：
    1. 🏬 **王府井 / 西单豪华商场**（名牌服装、床上用品、体育用品）
    2. 🛒 **便民生活超市**（生活日用品、新鲜食品、家用电器）
    3. 🏮 **雅秀市场 · 热闹夜市与货摊**（特色小吃食品、货摊卫衣、手工饰品）
    4. 🥬 **晨光生鲜传统早市**（清晨蔬菜瓜果、手工热包子早餐）
    5. 💻 **中关村 · 飞龙电子科技中心**（高性能笔记本电脑、5G智能手机、降噪耳机）
    6. 🏪 **街角便民小卖部**（学习用品笔记本与笔、冰镇矿泉水、小零食）
    7. 📱 **手机网购电商平台**（网站大额优惠券、好评热门商品、快递包裹）
- 🏷️ **课本生词精准对应商品 (Curriculum-Aligned Vocabulary Mapping)**：
  - 严格映射第 6 课《购物》生词表 1~38 及 5 大专有名词。
  - 每个商品对应特定的商品种类（体育用品、床上用品、家用电器、食品、学习用品、生活日用品）和商品特点（做工精细、款式新颖、料子讲究、质量可靠、价格划算/优惠、牌子/名牌）。
- 🎙️ **本地 Apple Silicon MLX IndexTTS 2.5 真实真人语音**：
  - 58 段高保真普通话语音（NPC 迎宾台词、分支对话剧情回应、商品重点句型、场景切换提示音）。
  - 自然温暖的生活化对话语调，告别机械生硬的机器人发音。
- 💬 **可折叠收起式底部对话栏 (Collapsible Dialogue Dock)**：
  - 完美解决遮挡店铺陈列与商品的问题，支持一键 `▼ 收起` 与 `▲ 展开`。
  - 提供 3 种地道互动表达分支（重点掌握「虽然……但是……」、「不如……」以及「先……然后……好吗？/ 怎么样？/ 行吗？」）。
- 📱 **完美适配 iPad 全屏沉浸体验**：
  - 支持一键 `⛶ 全屏`，针对 iPad / 平板视口与触控交互深度优化，无溢出滚动条。
  - 随身购物袋（背包结算系统）、逛街采购任务单（Quests）与破冰话题转盘。
- 📦 **单文件自包含架构 (Zero Dependencies)**：
  - 所有 3D 场景插画与高保真 MP3 音频均经过 Base64 编码内嵌，无需配置任何后端或静态资源服务器。
