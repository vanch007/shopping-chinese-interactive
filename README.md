# 一起逛街吧 · 场景中文对话 v2.0

手机优先、单屏操作的中文购物网页 App，适合越南学员与朋友一起练习。

[进入街区](https://vanch007.github.io/shopping-chinese-interactive/?v=story-v2-app)

从新街区地图进入七家店，点击画面里的店员，听招呼、选择中文回复，再听店员回应。每个回复关联具体商品，有些建议可以带你去下一家店。地图、店铺和对话各占一屏；固定顶部与底部导航，通过标签、跳转和翻页浏览，整页不需要上下滚动。

- 新的竖屏街区和七张店铺插画；店员和 21 件商品与交互标记一一对应。
- 店员招呼、三个回复分支、对应回应、商品查看和购买；会保留本设备的购物与对话进度。
- 49 句对话提供拼音、越南语翻译与解释，按需切换到学习详情；商品用“看商品 / 学词语 / 说一句”标签切换，48 个词语均有场景例子。
- 全量重制 153 段音频：7 段招呼、21 段店员回应、21 段玩家回复、21 段商品名称、21 段商品例句、48 段词语与例子、11 段场景/系统提示、3 段话题。
- 本地 MLX IndexTTS 2.5 8-bit；店员用用户指定的第一种音色，玩家回复用第二种音色。欢迎、解释、议价和轻快回应分别设置情感权重。
- 回复旁的“译 / ♫”进入学习详情并试听，点击句子才接话；自动朗读会先播放玩家，再播放店员。切换页面、隐藏页面或播放另一段会停止当前音频。
- 拼音、越南语、自动朗读可分别切换；支持 0.8×、1× 和 1.15× 速度。
- 优惠券免费领取，网购时减 25 元，只用一次；两瓶水与对话一致，合计 6 元。

## 单独一个文件

`index.html` 内嵌所有图片、语音、样式和剧情数据，没有运行时外部素材依赖。完整下载后可以在支持本地 HTML 的浏览器中离线使用。iPhone 可通过 Safari 打开在线版本，使用“添加到主屏幕”获得更完整的屏幕体验。

原始声音参考文件没有放入仓库或网页。未经压缩的生成文件和详细检查报告保留在本机忽略的 `work/`。

## 重建

维护 `template_game.html`、`game_data_rich.json`、`story_data.json` 或 `assets/` 后运行：

```sh
python3 compile_final_app.py
```

需要 Python 3 和 Pillow。构建核对全部语音键、翻译字段、商品引用和八张竖屏画面；从 MP3 源文件直接内嵌音频。
