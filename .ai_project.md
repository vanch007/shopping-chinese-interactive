# Shopping Chinese interactive lesson

- Deployment: https://vanch007.github.io/shopping-chinese-interactive/ ; repository `vanch007/shopping-chinese-interactive`, branch `main`.
- Deliverable: standalone `index.html`, with images, data and MP3 audio embedded.
- Source: `template_game.html`, `game_data_rich.json`, `assets/images/`, `assets/audio/`.
- Rebuild from any directory: `python3 /absolute/path/to/compile_final_app.py` (Pillow required). Build validates required voice keys and translations.
- Chinese NPC voice: IndexTTS 2.5 8-bit, user-supplied `vanch.m4a`; player choices: user-supplied `Bạn khỏe không .m4a`. Vietnamese reference is cloned to speak Chinese.
- Vietnamese support: translation of NPC greetings, choices and replies; optional explanations of words, sentence patterns and usage; product explanations.
- Manual emotion profiles: welcome, explain, lively, negotiate; player examples use calm delivery.
- Original voice references remain outside the repository. Uncompressed WAVs, generation manifests and detailed ASR reports remain in ignored `work/`; never publish original references.
- Dialogue audio is serialized using playback completion. Replay follows the displayed utterance. Switching scene or hiding the page stops playback; no system speech fallback.
- This iteration updates voices and learning support in the existing seven-scene app. The proposed phone-first multi-turn story redesign remains a separate planned iteration.
- Browser validation and release evidence: `docs/voice-release-2026-10-09.md`.
