# Shopping Chinese interactive lesson

- Deployment: https://vanch007.github.io/shopping-chinese-interactive/ ; repository `vanch007/shopping-chinese-interactive`, branch `main`.
- Current app: mobile-first, single-screen web app v2.0, new miniature-clay street and seven shop scenes with NPC/product hotspots.
- Deliverable: standalone `index.html`, with all eight images, story data, styles and 153 MP3 clips embedded; no runtime remote media.
- Source: `template_game.html`, `game_data_rich.json`, `story_data.json`, `assets/images/story-v2/`, `assets/audio/`.
- Rebuild: `python3 /absolute/path/to/compile_final_app.py` (Pillow required). Build validates audio coverage, Vietnamese fields, branch-to-product references, and portrait images.
- Layout: 100dvh shell with fixed header/dock; every functional view fits the viewport. Product tabs, paged notes/bag and paged learning details replace vertical scrolling. Portrait image frames are fitted to the available area before hotspot use.
- Flow: intro → map → scene → NPC dialogue → player branch → NPC reply → corresponding product / next shop. Dialogue is a separate page and never obscures scene hotspots.
- 7 distinct character voices designed for the 7 NPCs using MLX IndexTTS 2.5 8-bit with tailored references and emotions; second reference for 21 player replies. All speech is Chinese; Vietnamese is text guidance.
- Voice references remain outside the repository. Raw WAVs, manifests and detailed ASR checks remain in ignored work/. Never publish original recordings.
- Audio is serialized by playback completion; navigation/visibility change cancels playback. No speechSynthesis fallback. Direct play buttons remain available if mobile autoplay is blocked.
- Persistent state key shopping-story-v2: budget ¥2000, purchased product kinds, visited/talked scenes, learned words, language and speed settings. Old app state is not reused.
- Goal: talk to 3 distinct NPCs and buy 3 product kinds. Online coupon reduces one order by ¥25. Water purchase is two bottles / ¥6, matching its dialogue.
- Evidence and release record: docs/story-v2-release-2026-10-09.md. Physical iPhone Safari verification remains separate from responsive browser checks.
