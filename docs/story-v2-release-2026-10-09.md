# 一起逛街吧 v2.0 · 单屏网页 App

本轮交付重构画面、剧情、交互和全部音频。旧版仅做了部分对话音频与学习说明的更新，没有落实完整的场景重设计；本轮用新的独立文件替换旧入口。

## 交付内容

- 新街区地图、七张竖屏店铺场景；各有对应店员与三件可点的实物。
- 固定导航与单屏视图：开场、地图、地点目录、场景、对话、商品、购物袋、笔记、话题和学习详情。
- 七位店员、21 条回复分支及对应回应；每条分支关联正确商品，早餐/网购试穿分支还可去商场。
- 商品通过“看商品 / 学词语 / 说一句”切换；词语、购物袋与长解释按屏幕空间分页。
- 拼音、越南语、解释、试听与返回接话；中文台词有越南语用法帮助。
- 单独 `index.html` 内嵌八张图、全部数据和 153 段 MP3，无运行时素材或字体网络依赖。

## 全量语音替换

所有发布音频均使用本地 MLX IndexTTS 2.5 8-bit 重新生成，采用明确的中文语言与手动情感权重。七位 NPC 针对角色人设进行了独立音色设计：小林（步非烟-讲解，知性端庄商场导购）、阿明（东北男声，热情干练超市小哥）、老周（天津大爷，幽默豪爽市井大叔）、小陈（雷军科技感声音，沉稳专业数码顾问）、陈阿姨（贾玲质朴声音，亲切接地气早市阿姨）、王奶奶（上海妹子0.88x慢速，慈祥温和长辈）、小安（八音神子，灵动甜美AI客服助手）。21 条玩家回复保留第二段学员音色（Bạn khỏe không）；词语、商品与系统提示保持标准清晰示范。原始参考录音未放入公开仓库或 HTML。
