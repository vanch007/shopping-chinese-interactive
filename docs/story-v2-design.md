# 一起逛街吧 · 手机场景对话版

## Design brief

- Purpose: 通过真实购物意图练习中文；越南学员能听、选、理解，并和朋友继续口头对练。
- Audience: 手机竖屏为主，保留 iPad 和桌面；日常中文学习者。
- Archetype: Lo-Fi。暖纸色界面、深墨色文字、砖红主操作；场景为温暖哑光定格动画风插画。
- Differentiation: NPC 与三件实际商品共同出现在场景；点人物开始，选择台词后接到对应回应，再买东西、换话题或去下一家。
- Avoid: 大地图堆长标签；用作背景但无对应人物/商品的插图；对话弹层遮住画面；购买优惠券；系统合成语音回退。

## Story and flow

主线：和朋友准备周末聚会。完成三位 NPC 的对话，并带回三种商品。初始预算 ¥2000。

开场页 → 街区地图 → 店铺场景 → 点 NPC → NPC 开场 → 玩家选择并朗读 → NPC 对应回应 → 查看相关商品／继续聊／去另一家。

七个场景：早市、小卖部、超市、商场、电子中心、夜市、网上小店。每个场景三条与具体商品相关的分支。早市早餐分支和网购试穿分支可直接引导去商场；其他场景也能自由返回地图。

购买会真实改变预算和购物袋；优惠券免费领取，仅用于网上商品，最多一张，仅一次订单省 ¥25，不重复扣钱或重复消费优惠券。

进入新场景不自动播系统音。点击 NPC 才开始对话。所有可朗读文字都对应本轮 IndexTTS 2.5 音频；NPC、商品、词语和例句用 vanch；玩家选项用第二段用户参考录音。

## Visual specification

- 竖屏：顶部约 54px 导航、中央完整场景、底部 68px 导航；场景使用 contain 保持热点与实物对应。
- 全站使用单屏 App 布局：100dvh 外壳、固定顶栏和底栏，无整页纵向滚动。
- 对话一次显示当前 NPC 台词与三条中文回复；“拼音 / 越语 / 解释”切换到详情页，返回继续对话。回复旁“译 / ♫”可先理解和试听。
- 商品分为看商品、学词语、说一句；词语、笔记、购物袋和长解释按当前高度分页。横屏使用并排布局。
- 最小按钮 48px；主要操作至少 48px。地图另外提供地点目录按钮。
- 纸色主背景 #f7f1e5、墨色 #29291f、辅助绿 #50644a、主强调砖红 #a43e2e；正文对比至少 4.5:1。
- 标题使用本地中文衬线，正文使用可读的本地中文/越南语字库；无外部字体依赖。
- 记录预算、购物袋、领取的优惠券、对话进度和生词到浏览器本地；存储不可用时会话内仍可运行。
- 开场显式显示“场景对话版 2.0”，页面 title 与分享信息同步更新。

## Mobile checkpoint

Platform: iPhone/Android 浏览器；iPad 兼容。
Framework: 原生 HTML/CSS/JavaScript，独立 HTML。
References: mobile-design 的思考、触摸、性能、离线、测试、调试与 iOS/Android 参考；frontend-design Lo-Fi。
Principles: 拇指可达的主要动作；图片与内容分区；固定比例素材和坐标避免裁切；播放终止与导航取消一致。
Avoid: 悬停才能操作、画面上叠大段台词、横向溢出、浏览器语音回退、活动标签不断漂浮。
MFRI: 平台明确 5 + 可访问性 5 - 交互 2 - 性能 2 - 离线依赖 1 = 5。需浏览器响应式与真实音频播放核查；真机范围据实报告。

## Acceptance

- 开场、地图、店铺、对话、商品、购物袋、学习笔记均可跳转。
- 七幅场景与对应 NPC、三件商品一致；热点在图像坐标系内。
- 教材核心生词保留，共 48 个词语对应具体商品/场所；词语、句型和越南语解释可读可听。
- 两种参考录音映射可审计；所有播放键都使用本轮新音频。
- 320/390/430px 手机、768px 平板与手机横屏可操作；全屏控件不溢出；浏览器后退不丢失预算或购买。
- 上线页面哈希与交付的独立 index.html 一致，显示 2.0 版本。
